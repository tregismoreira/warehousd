# Phase 4 — SSO: OIDC, JIT, IdP-Delegated MCP Login (Execution Outline)

> **Status: outline.** Expand with superpowers:writing-plans before executing. Spec: `docs/SPECS.md` §6.1–6.4 (items 1–3). Roadmap: Phase 4. §10 test 11.
