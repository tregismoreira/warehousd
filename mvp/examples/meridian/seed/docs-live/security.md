# Information Security Policy

## General Security Principles
All employees must comply with this security policy to protect company assets and client data. Information security is everyone's responsibility.

## Access Control
- Use strong passwords (minimum 14 characters, mixed case, numbers, symbols)
- Change passwords every 90 days
- Never share login credentials
- Report unauthorized access attempts immediately

## Data Classification
- **Public**: Can be shared externally (marketing materials, public announcements)
- **Internal**: For internal use only (org charts, internal processes)
- **Confidential**: Restricted access required (financial data, client contracts)
- **Secret**: Highest security level (security keys, authentication credentials)

## Incident Response
- Immediately report suspected breaches to security@company.com
- Do not attempt to investigate or remediate without security team guidance
- Complete incident report within 24 hours of discovery

## Remote Work Security
- Always use VPN when accessing company systems from non-company networks
- Enable endpoint detection and response (EDR) on all devices
- Encrypt all devices with approved full-disk encryption
- Lock computer when stepping away, even briefly
